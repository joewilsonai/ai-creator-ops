# X / Twitter AI creator platform notes

Date checked: 2026-05-18
Platform record: `x-twitter`
Primary source IDs: `x-api-create-post`, `x-api-media-upload`, `x-developer-guidelines`, `x-creator-revenue-sharing`, `x-authenticity-policy`, `x-content-monetization-standards`

## Operator answer

X is useful for conversation, lore, distribution, and founder/operator visibility for AI influencers, virtual influencers, AI model brands, and AI companion businesses. It has official API posting/media support, but automation must avoid spam, unsolicited interactions, engagement manipulation, and undisclosed AI/sponsored contexts.

## Source-backed points

- X API v2 Create/Edit Post docs expose `POST /2/tweets` and include `made_with_ai` and `paid_partnership` fields relevant to AI media and sponsorship disclosure.
- X media upload docs describe an official endpoint for uploading media for posts and other content.
- X Developer Guidelines emphasize user-initiated actions, transparency, easy opt-out, official API usage, limits, and legitimate value.
- Developer guidance flags identical content across multiple accounts, trend manipulation, unsolicited auto-replies, unsolicited bulk DMs, and engagement-selling patterns as prohibited/high-risk.
- X Creator Revenue Sharing eligibility requires Premium/Premium Business/Premium Organizations, 5M organic impressions in the last 3 months, 500 verified followers, supported payout geography, and compliance with X rules/agreements.
- X Creator Revenue Sharing states payouts are currently every two weeks with a $30 minimum and that participation can be modified, cancelled, accepted, or revoked at X's discretion.
- X Help states that effective 2026-03-03, users posting AI-generated videos of armed conflict without disclosure receive a 90-day Creator Revenue Sharing suspension, with subsequent violations causing permanent payment suspension.

## Editorial implications

- Position X as automation-capable but not automation-for-anything.
- Treat monetization as possible but volatile and eligibility-gated.
- AI companion/AI girlfriend operators should separate public conversation from any sensitive DM monetization or adult funnel logic.

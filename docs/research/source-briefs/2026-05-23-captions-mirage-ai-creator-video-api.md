## Executive summary

Captions is now source-backed enough to add as an AI Creator Ops tool record. The official Captions Help Center describes an AI Creator API that can generate AI videos programmatically using community avatars or a user's AI Twin, with scripts up to 800 characters, outputs up to one minute, support for 30+ languages, and a list/submit/poll/download workflow. Captions' API pricing page describes duration-based API pricing for styled captions and Mirage Video 1 generation, while the consumer pricing page positions AI Creator, AI Twin, AI video, AI voiceover, AI lipdub, and export workflows inside subscription tiers.

This is directly relevant to AI influencer, virtual influencer, and synthetic presenter operations because it gives operators a documented path for recurring talking-head videos rather than purely manual app workflows. It should be treated as a medium-risk synthetic media tool: useful for scaled creator clips, but public claims need to cite Captions/Mirage terms, acceptable-use policy, and privacy/biometric handling before recommending identity-clone or AI girlfriend workflows.

## High-confidence primary-source findings

1. **Captions has an official AI Creator API for programmatic avatar videos.** The Captions Help Center says the API can generate videos programmatically using community avatars or a user's AI Twin, supports 30+ languages, uses `/list`, `/submit`, and `/poll` paths, and downloads the completed video after generation. Scripts are limited to 800 characters and videos are currently limited to one minute.
   - Primary source: <https://captions.ai/help/api-reference/ai-creator>

2. **The AI Creator API uses credits and has explicit per-second usage language.** The same AI Creator API guide says the API consumes 1 credit per second; a 30-second video would consume 30 credits. Users can view remaining credits and purchase more through the API dashboard.
   - Primary source: <https://captions.ai/help/api-reference/ai-creator>

3. **Captions/Mirage publishes API pricing for captioning and video generation.** The API pricing page says styled captions are billed by input-video length rounded up to the nearest minute, while Mirage Video 1 video generation is billed by generated output length rounded up to the nearest six-second increment. The page lists styled captions at $0.15/minute and Mirage Video 1 at $0.175/second as of retrieval.
   - Primary source: <https://captions.ai/help/docs/api/pricing>

4. **Captions' public pricing page includes AI creator-relevant features.** The official pricing page lists AI Creator, AI Ads, AI Skits, AI Twin, AI Edit, AI Music, AI Sounds, AI Voiceover, AI Image, AI Video, AI Translate, AI Lipdub, AI Shorts, Reddit to Reel, AI Voice Clone, and related export/caption features across plans. It also states that unused credits can roll over up to two extra months, allowing a balance up to 3x the monthly allowance.
   - Primary source: <https://captions.ai/pricing>

5. **Captions/Mirage terms require policy review before strong commercial recommendations.** The Captions terms say users own input and output as between the parties, subject to Mirage/Mirage-content rights, but grant Mirage a license to use input and output to provide and improve services and develop new products. API terms restrict using the Mirage API, service, or output to create, train, fine-tune, evaluate, or otherwise improve competing AI/ML systems. The privacy policy also notes that AI-based features may share information with third-party partners and that Mirage may process face/voice-related biometric information for some features.
   - Primary sources: <https://captions.ai/terms>, <https://www.captions.ai/terms/api>, <https://captions.ai/privacy>

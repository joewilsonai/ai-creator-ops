# Source brief: TikTok Content Posting API and AIGC labeling

Date: 2026-05-17

## Focus

TikTok automation and AI-generated content policy signals for AI creator businesses using TikTok as a discovery and funnel channel.

## Why it matters for AI Creator Ops

TikTok remains a high-leverage discovery surface for synthetic creators, but it has two operational constraints that should be visible in platform/tool intelligence:

1. Publishing automation is possible through TikTok's official Content Posting API, but production/public visibility depends on scopes, creator account state, and an app audit.
2. Realistic AI-generated or significantly AI-edited media must be labeled under TikTok's AIGC guidance; some uses remain prohibited even if labeled.

## Primary sources reviewed

### 1. TikTok Content Posting API: Get Started

URL: https://developers.tiktok.com/doc/content-posting-api-get-started

Key evidence:

- TikTok's guide says the Content Posting API can post videos or photos directly to a creator's TikTok account.
- Direct posting requires the posting permission scope shown in the docs (`video.publish`).
- TikTok says content posted by unaudited clients is restricted to private viewing mode.
- To lift that visibility restriction, the API client must undergo an audit for compliance with TikTok's Terms of Service.
- The API flow requires querying creator info before posting because posting capabilities can vary by account/current settings.

Operational implication:

- Treat TikTok automation as officially supported but not frictionless. A creator ops stack should not assume public unattended posting until the app/audit path and account capabilities are verified.

### 2. TikTok Content Posting API product page

URL: https://developers.tiktok.com/products/content-posting-api/

Key evidence:

- TikTok describes Content Posting APIs as compatible with desktop, cloud, and web applications.
- TikTok identifies two posting modes: Direct Post API, which posts to a profile from an app, and Upload API, which uploads draft content for later editing/posting in TikTok's creation flow.

Operational implication:

- For AI creator workflows, the safer fallback is draft upload/review where direct public posting approval is not available.

### 3. TikTok Support: About AI-generated content

URL: https://support.tiktok.com/en/using-tiktok/creating-videos/ai-generated-content

Key evidence:

- TikTok defines AI-generated content as images, video, and/or audio generated or modified by artificial intelligence.
- TikTok says creators are encouraged to label content completely generated by AI or significantly edited by AI.
- TikTok says creators are required to label AI-generated content that contains realistic images, audio, or video.
- TikTok says content made only with TikTok AI effects may be automatically labeled, but independently altered content should still follow the labeling guidelines.
- TikTok says AIGC can be automatically labeled when uploaded with C2PA Content Credentials.
- TikTok warns that some AI-generated or edited media is prohibited even if labeled, including certain public-figure, crisis-event, minor, or non-consensual private-adult depictions.

Operational implication:

- AI creator TikTok workflows should include a labeling decision gate before publish and avoid realistic impersonation/deepfake-style content that triggers higher policy risk.

## Suggested AI Creator Ops updates

- Mark TikTok as having official publishing API support with caveats around app audit and account capability checks.
- Keep TikTok policy risk at `medium` until a deeper platform-policy review is complete; the platform allows AIGC with labels in some cases but has explicit restrictions on realistic synthetic media.
- Add these primary sources to the TikTok platform record.

High for API existence, audit restriction for unaudited clients, direct/draft posting modes, and AIGC labeling requirements because all are from official TikTok sources.

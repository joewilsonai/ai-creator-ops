## High-confidence primary-source findings

### Runway API is positioned as an embeddable generative media layer

- Source: Runway API Documentation, https://docs.dev.runwayml.com
- Evidence: Runway states that the API lets builders bring its generative models into "apps, products, platforms and websites." The docs expose SDK examples for Gen-4.5 image-to-video generation using Node and Python.
- AI Creator Ops relevance: Runway should be tagged as usable for creator automation workflows, not just manual generation. This supports future updates to the Runway tool page, creator automation stack guide, and Runway vs Kling comparison.
- Confidence: high; official developer docs.

### Runway Characters API is live for real-time conversational AI avatars

- Source: Runway API Documentation, https://docs.dev.runwayml.com
- Evidence: The docs state: "New: Characters API is now in live. Build real-time conversational AI avatars."
- AI Creator Ops relevance: This is directly relevant to AI companion creators, AI girlfriend operators, live virtual influencers, and interactive fan-funnel concepts. Public claims should still be careful until implementation docs and constraints are source-reviewed.
- Confidence: high for existence; implementation details need deeper source review.

### Runway API pricing is credit-based with published model rates

- Source: Runway API Pricing & Costs, https://docs.dev.runwayml.com/guides/pricing
- Evidence: Runway says credits can be purchased for $0.01 per credit. Published rates include:
  - `gen4.5`: 12 credits per second
  - `gen4_turbo`: 5 credits per second
  - `gen4_aleph`: 15 credits per second
  - `act_two`: 5 credits per second
  - `gen4_image`: 5 credits per 720p image or 8 credits per 1080p image
  - `gen4_image_turbo`: 2 credits per image
  - `gwm1_avatars`: 2 credits upfront, then 2 credits per 6 seconds
- AI Creator Ops relevance: This gives a concrete cost model for a future AI Creator Stack Cost Calculator and for Runway/Kling/video-generator comparisons. Use the docs as the authority for pricing; do not rely on YouTube/X pricing claims.
- Confidence: high; official pricing docs.

### Runway Gen-4.5 web product supports text-to-video and image-to-video at 720p, 24/25fps

- Source: Runway Help Center, Creating with Gen-4.5, https://help.runwayml.com/hc/en-us/articles/46974685288467-Creating-with-Gen-4-5
- Evidence: Runway states Gen-4.5 offers Text to Video and Image to Video controls, costs 12 credits per second, supports 2-10 second durations, outputs 720p, and supports multiple aspect ratios for image-to-video including 9:16.
- AI Creator Ops relevance: 9:16 image-to-video is directly relevant to TikTok/Reels/Shorts synthetic influencer production. Keep claims scoped to current source text and include last-checked dates when public pages are updated.
- Confidence: high; official help center.

### OpenAI's image generation API supports GPT Image generation/editing and multi-turn image workflows

- Source: OpenAI API Image Generation docs, https://developers.openai.com/api/docs/guides/image-generation
- Evidence: OpenAI documents Image API endpoints for image generations/edits and Responses API image generation for conversational or multi-step workflows. The docs identify `gpt-image-2`, `gpt-image-1.5`, `gpt-image-1`, and `gpt-image-1-mini` as GPT Image models and note that API organization verification may be required.
- AI Creator Ops relevance: Useful source for GPT Image tool page and identity-consistency workflows, especially iterative editing and character reference workflows. Public page should verify current model availability/pricing separately against official docs/pricing.
- Confidence: high for feature availability described in docs.

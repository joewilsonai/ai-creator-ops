## Operator takeaway

X / Twitter is useful for fast audience testing, persona voice, founder/operator commentary, and funnel traffic for AI influencers and virtual creators. It is less reliable as a primary monetization platform because reach, paid features, and API economics can shift. Treat it as a distribution and signal surface with strict disclosure controls for realistic synthetic media.

## Source-backed notes added

- X API v2 supports creating or editing posts for an authenticated user.
- The create-post documentation includes `made_with_ai` and `paid_partnership` fields that can be used for relevant labels.
- X developer announcements document X API v2 media-upload endpoints for images and video.
- X’s synthetic/manipulated media policy language says users may not deceptively share synthetic or manipulated media likely to cause harm, and X may label such media for context.

## Editorial treatment

- Use `X / Twitter` in H1/entity labels because users still search for Twitter.
- Do not imply that API access is free or unrestricted; pricing and access tiers need separate source review before hard claims.
- Recommend separate disclosure controls for realistic synthetic media, sponsorships, and character-lore posts.

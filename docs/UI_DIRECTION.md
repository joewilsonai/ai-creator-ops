# UI Direction

## Recommended UI

Best UI: dark editorial intelligence product with data-rich cards and clean documentation ergonomics.

Think:
- Linear precision
- Bloomberg / CB Insights seriousness
- Stripe-grade clarity
- Perplexity-style citations
- Mintlify documentation readability
- A little neon synthetic edge, but not crypto casino nonsense

## Why this is the best fit

AI Creator Ops needs to look like an authority source, not an affiliate blog. The UI should say:

- researched
- current
- structured
- data-backed
- serious enough to cite
- practical enough to use

The site should feel like a publication plus database plus operating manual.

## Visual language

Palette:
- Background: near-black / ink navy `#07080c`
- Surface: charcoal `#10131a`
- Elevated cards: `#151923`
- Text: soft white `#f4f5f7`
- Muted text: `#9aa3b2`
- Border: `#252b38`
- Primary accent: electric violet `#8b5cf6`
- Secondary accent: cyan `#22d3ee`
- Positive/data accent: emerald `#34d399`
- Warning/policy accent: amber `#f59e0b`

Typography:
- Primary: Geist or Inter
- Data/code: Geist Mono or JetBrains Mono
- Large headings: tight tracking, high contrast, no bubbly startup feel

Component style:
- Dense but readable cards
- Comparison tables
- Score badges
- Last-updated chips
- Source/citation drawers
- Glossary entity cards
- Changelog timeline
- Filterable tool/platform index
- Editorial article pages with answer blocks and methodology links

## Page design principles

Every serious content page should include:
- direct answer block
- key facts
- table of contents
- last updated date
- source list
- related pages
- internal glossary links
- score/methodology when ranking anything
- FAQ schema-ready block

## Design systems to borrow from

Primary inspiration: Linear dark-mode precision.
Secondary: Mintlify docs readability and Stripe content clarity.
Avoid: generic SaaS gradients, fake 3D blobs, affiliate-blog clutter.

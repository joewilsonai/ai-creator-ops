# Site Architecture

## Top-level navigation

- Guides
- Tools
- Platforms
- Comparisons
- Reports
- Glossary
- News
- Templates
- Methodology

## Content types

### Guides
Evergreen operating manuals.

Examples:
- how to build an AI creator brand
- AI creator identity consistency
- AI creator automation stack
- monetization funnel guide

### Tools
Database-backed tool pages.

Fields:
- name
- category
- best_for
- creator_use_cases
- pricing
- API availability
- commercial rights notes
- platform risk notes
- alternatives
- sources
- last_checked

### Platforms
Platform intelligence pages.

Fields:
- platform type
- AI creator friendliness
- monetization options
- automation/API support
- policy notes
- enforcement risk
- latest updates

### Comparisons
High-intent decision pages.

Examples:
- Fanvue vs OnlyFans
- Runway vs Kling
- GPT Image vs Midjourney
- Buffer vs Metricool

### Reports
Original data and linkable assets.

First flagship report:
- AI Creator Platform Index 2026

### Glossary
LLM/AEO entity pages.

Examples:
- AI creator
- synthetic influencer
- identity consistency
- fan platform
- DM automation
- provenance

### News / Changelog
Focused updates only. No generic AI news.

Use for:
- pricing changes
- policy changes
- new model releases
- scheduler/API updates
- monetization changes

## LLM SEO surface

- `/llms.txt`
- `/sitemap.xml`
- `/feed.xml`
- JSON-LD schema on guides, tools, FAQs, breadcrumbs, organization, author/reviewer
- stable entity URLs
- clear definitions and citations
